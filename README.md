# Auto_Prime — сайт автосалона «АвтоПрайм»

Учебный проект по веб-разработке: статический сайт мультибрендового автосалона
«АвтоПрайм» (г. Симферополь). Четыре адаптивные страницы на HTML5, CSS3 и чистом
JavaScript, без сборщиков и зависимостей.

**Демо (GitHub Pages):** https://pti4kaexe.github.io/Auto_Prime/

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: первый экран, подбор автомобиля, популярные модели, преимущества, кредит, trade-in, отзывы |
| `catalog.html` | Каталог из 8 моделей: фильтры по марке, кузову, цене, КПП и приводу, сортировка, счётчик результатов |
| `car.html` | Карточка автомобиля: галерея, вкладки характеристик/комплектаций/описания/отзывов, кредитный калькулятор |
| `contacts.html` | Контакты: карточки с контактами, схема проезда, форма обратной связи, реквизиты |

## Структура

```
├── index.html
├── catalog.html
├── car.html
├── contacts.html
├── css/        common.css, index.css, catalog.css, car.css, contacts.css
├── js/         data.js, main.js, catalog.js, car.js, contacts.js
└── img/        logo.svg, hero.webp, cars/ (8 фото), gallery/ (3 кадра)
```

## Как запустить локально

Открыть `index.html` в браузере — сервер не требуется, все пути относительные.

## Что реализовано

- адаптивная вёрстка (проверено на 1440, 1100, 900, 640 и 390 px), бургер-меню;
- каталог: фильтры, сортировка, счётчик, параметры подбора сохраняются в адресной строке;
- карточка: галерея, вкладки, кредитный калькулятор с пересчётом платежа;
- модальное окно записи на тест-драйв и валидация форм;
- оптимизация графики: WebP вместо JPEG (−68 % веса), SVG-логотип, `loading="lazy"`.

## Деплой

Сайт публикуется на GitHub Pages из ветки `main` (папка `/`). После включения
Pages в настройках репозитория каждое изменение в `main` автоматически обновляет сайт.
